# 🚀 Stealth Node v2.0: Dual VLESS (TCP-Reality + XHTTP-Reality) + SNI Multiplexer

Универсальный скрипт для автоматического развертывания высокоскоростного, устойчивого к блокировкам (ТСПУ / РКН / мобильные операторы) прокси-узла на базе **Xray Core** и **3x-ui** с L4 SNI-мультиплексированием на порту 443 и маскировкой под инфраструктуру **Apple** и легитимный веб-хостинг.

---

## 🛡️ Архитектура и Ключевые Особенности

```text
                                Входящие соединения на 443 порт (Nginx Stream)
                                                      │
         ┌────────────────────────────────────────────┼────────────────────────────────────────────┐
         │                                            │                                            │
SNI: gateway.icloud.com                      SNI: www.apple.com                          Ваши домены (site/panel)
         │                                            │                                            │
         ▼                                            ▼                                            ▼
127.0.0.2:443 (Xray)                         127.0.0.3:443 (Xray)                         127.0.0.1:8444 (Caddy)
VLESS + TCP + XTLS-Vision + Reality          VLESS + XHTTP + Reality                      Белый сайт AetherCloud +
⚡ МАКСИМАЛЬНАЯ СКОРОСТЬ                      🛡️ АНТИ-DPI / ОБХОД ШЕЙПИНГА                 Защищенная панель 3x-ui
(До 1 Гбит/с, 4K, YouTube, BBR)              (Имитация HTTP/2-потоков, Cloudflare-ready)  (RFC 421 strict_sni_host)
```

### 1. Двойной стек VLESS на едином порту 443:
* **Канал №1 (Скоростной):** `VLESS + TCP + XTLS-Vision + Reality` (маскировка под `gateway.icloud.com`). Дает максимальную скорость физического канала (до 1 Гбит/с), нулевой оверхед и минимальный пинг.
* **Канал №2 (Анти-DPI):** `VLESS + XHTTP + Reality` (маскировка под `www.apple.com`). Дробит трафик на серию HTTP-потоков. Обходит поведенческий анализ долгих TCP-сессий и готов к работе через бесплатный Cloudflare CDN в случае бана IP сервера.

### 2. Маскировка под инфраструктуру Apple:
* В качестве целевых серверов REALITY используются дата-центры **Apple (`gateway.icloud.com` и `www.apple.com`)** с поддержкой TLS 1.3 и ALPN H2.
* Пинг до серверов проверки составляет 5–15 мс без разрыва сокетов и зависаний в `SYN-SENT`.
* При попытке активного зондирования (пробинга) со стороны сканеров РКН/ТСПУ сервер отдает **подлинный сертификат Apple**.

### 3. Обход фильтрации мобильных операторов (МТС / Билайн / Мегафон / Т2):
* Профиль uTLS по умолчанию настроен на **`fp=firefox`**, что предотвращает избирательное глушение и дропы пакетов ClientHello, характерные для мобильных сетей РФ.
* Удалены нестабильные экспериментальные постквантовые расширения (`x25519mlkem768`), вызывающие сбросы соединений на ТСПУ.

### 4. Аппаратное сетевое ускорение (BBR + FQ):
* На уровне ядра Linux активирован алгоритм контроля перегрузок **Google BBR** с дисциплиной очереди **FQ** и расширенными сетевыми буферами `rmem`/`wmem`.
* Включен `net.ipv4.ip_forward = 1` для бесперебойной маршрутизации в TUN/VPN режимах.

### 5. Защита сервера от абуз и утечек (Routing Isolation):
* В ядро Xray встроены строгие правила изоляции трафика:
  * **BitTorrent блокирован на корню:** защищает ваш VPS от абуз правообладателей (DMCA) и бана со стороны европейских хостинг-провайдеров.
  * **Изоляция RU-сегмента:** запросы к `domain:ru`, `domain:su`, `geosite:yandex`, `geosite:vk`, `geoip:ru` сбрасываются в `blackhole` — сервер не тратит трафик на заблокированные извне российские сервисы (Госуслуги, банки) и направляет клиентов через локальный интернет.

### 6. Защита от активного сканирования (Anti-Probing & Zero Exposure):
* **Caddy с директивой `strict_sni_host` & `admin off`:** при несовпадении TLS SNI и заголовка HTTP Host сервер строго по RFC 9110 возвращает `421 Misdirected Request` или разрывает TLS. Неавторизованный Admin API порт 2019 отключен. Вырезаны раскрывающие заголовки (`Server: Caddy`, `Via`, `Alt-Svc`).
* **Защита от поисковиков и сканеров:** заголовок `X-Robots-Tag: noindex, nofollow, noarchive` и виртуальный `/robots.txt` предотвращают индексацию витрины и панели в поисковых системах.
* **Порт 80:** прямые запросы по IP или чужим доменам сбрасываются мгновенно с кодом `444 No Response`.
* **Zero Public Port:** панель 3x-ui и подписки привязаны строго к `127.0.0.1` и доступны только через обратный прокси Caddy по секретным случайным путям. В файрволе (UFW) открыты только три порта: SSH, 80 и 443.

### 7. Комплексный харденинг безопасности (Hardening):
* **CrowdSec IDS + Firewall Bouncer + Fail2ban:** гибридная система обнаружения вторжений анализирует логи в реальном времени и банит сканеры и брутфорс на уровне ядра (nftables/iptables).
* **Изоляция логов:** файлы логов Xray ограничены правами `660` для группы демона (`root:xui`), без открытого доступа для других процессов.
* **Безопасность SSH:** отключен `X11Forwarding` для предотвращения перехвата сессий, вход root запрещен.

## 📋 Требования к серверу

* **ОС:** Чистая Ubuntu 22.04 LTS или 24.04 LTS (x86_64).
* **2 домена (или поддомена):**
  * **Домен №1:** Для белого сайта-витрины (например: `site.mydomain.com`).
  * **Домен №2:** Для панели управления 3x-ui и подписок (например: `panel.mydomain.com`).
* **DNS:** Оба домена должны иметь A-запись, указывающую на публичный IP вашего сервера.

## ⚡ Быстрый запуск

Зайдите на чистый сервер по SSH под пользователем `root` и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/avan-gintof/xhttp-reality-installer/main/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

*(Либо скопируйте `install.sh` на сервер вручную)*:

```bash
chmod +x install.sh
./install.sh
```

## 💬 Что запросит скрипт при установке?

1. **Домен №1** — домен для витрины (белого сайта).
2. **Домен №2** — домен для панели 3x-ui и подписок.
3. **SSH порт** (по умолчанию `22`, можно указать нестандартный для защиты от брутфорса).
4. **Логин и пароль администратора** (по умолчанию генерируются надежные случайные).

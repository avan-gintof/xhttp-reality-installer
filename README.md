# 🚀 Скрипт автоматического развертывания Stealth Node

Универсальный скрипт для полной автоматической настройки устойчивого к блокировкам (DPI/ТСПУ) прокси-узла на базе **Xray (VLESS + XHTTP + REALITY)** с маскировкой под полноценный многодоменный веб-хостинг.

---

## 🛡️ Ключевые особенности архитектуры

1. **L4 SNI-мультиплексирование (Nginx Stream на порту 443):**
   * Запросы с SNI маскировки (`000.canonical.com`, `canonical.com`) передаются в Xray REALITY (`127.0.0.2:443`).
   * Запросы к вашим доменам (`site.domain.com`, `panel.domain.com`) передаются в Caddy (`127.0.0.1:8444`).
   * Снаружи сервер выглядит как стандартный белый веб-хостинг с несколькими сайтами.

2. **Защита от активного зондирования (Anti-Probing):**
   * **`strict_sni_host` в Caddy**: при несовпадении TLS SNI и HTTP Host сервер строго по RFC выдает `421 Misdirected Request` вместо случайных ответов.
   * Вырезаны все раскрывающие заголовки (`Server: Caddy`, `Via`, `Alt-Svc`).
   * **Порт 80**: прямые запросы по IP или поддельным доменам сбрасываются мгновенно (`return 444;`).

3. **Современный транспорт VLESS + XHTTP:**
   * Включен HTTP-паддинг запросов (`xPaddingBytes: 100-1000`).
   * Потоковая загрузка (`scStreamUpServerSecs: 20-80`, `scMaxBufferedPosts: 30`).
   * Трафик выглядит как обычный HTTP/2-обмен данными с веб-сервером.

4. **Полная изоляция сервисов (Zero Public Exposure):**
   * Панель **3x-ui** и подписки привязаны строго к `127.0.0.1` и доступны только через обратный прокси Caddy по секретным случайным путям.
   * Наружу в файрволе (UFW) открыты **только три порта**: выбранный порт SSH, 80 и 443.

5. **Встроенный шаблон сайта:**
   * На первый домен автоматически устанавливается красивый современный адаптивный лендинг облачной IT-инфраструктуры (чистый HTML5/CSS3 без чужих копирайтов и заглушек).

6. **Автоматические обновления безопасности (Unattended-Upgrades):**
   * Скрипт перед началом полностью обновляет систему и настраивает фоновую авто-установку критических патчей безопасности Ubuntu без вмешательства пользователя.

---

## 📋 Требования к серверу

* **ОС:** Чистая Ubuntu 22.04 LTS или 24.04 LTS (x86_64).
* **2 домена (или поддомена):**
  * Домен №1: Для белого сайта-витрины (например: `site.mydomain.com`).
  * Домен №2: Для панели управления 3x-ui и подписок (например: `panel.mydomain.com`).
* **DNS:** Оба домена должны иметь A-запись, указывающую на публичный IP вашего сервера.

## ⚡ Быстрый запуск

Зайдите на ваш чистый сервер по SSH под пользователем `root` и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ/main/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

*(Или скопируйте файл `install.sh` на сервер вручную)*:

```bash
chmod +x install.sh
./install.sh
```

---

## 💬 Что запросит скрипт при установке?

1. **Домен №1** — домен для витрины (белого сайта).
2. **Домен №2** — домен для панели 3x-ui и ссылок подписки.
3. **SSH порт** (по умолчанию стандартный `22`, либо можно указать свой).
4. **Домен прикрытия REALITY** (по умолчанию `www.versio.nl` — хостинг в Нидерландах с поддержкой TLS 1.3 и HTTP/2).
5. **Логин и пароль администратора** (если нажать Enter, скрипт сгенерирует надежные случайные учетные данные).

## 🏁 Что выведет скрипт в конце:

* Команду подключения по SSH на новый порт (`ssh -p ПОРТ root@IP`).
* Прямую ссылку на панель управления 3x-ui с секретным путем и логином/паролем.
* Ссылку на ваш рабочий сайт.
* **Готовую готовую ссылку `vless://...` для мгновенного импорта** в клиенты:
  * Windows: *v2rayN*, *NekoBox*
  * Android: *v2rayNG*, *NekoBox*, *Hiddify*
  * iOS: *Streisand*, *V2Box*, *FoXray*, *Shadowrocket*
  * macOS: *V2rayXS*, *Hiddify*
